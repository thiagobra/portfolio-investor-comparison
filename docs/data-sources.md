# Data sources

Everything here is downloaded once, committed as plain markdown/JSON in
`data/`, and re-generated by `tools/build_reference_data.py` when you want
fresher numbers. Nothing in the running app calls out to the network.

## 1. Industry correlation + volatility — Kenneth R. French Data Library

`https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/12_Industry_Portfolios_CSV.zip`

Monthly returns for 12 industries, Dartmouth, free, no registration,
academic standard. Used to build the sector correlation matrix and
per-sector annualised volatility in `data/correlations.md` /
`data/volatility.md`. (A 48-industry file exists at the same path with
`48_` in place of `12_` if a finer split is ever wanted — 12 keeps the
matrix legible and matches the app's sector taxonomy closely enough.)

## 2. Region correlation — Ken French regional 3-factor files

Same library, ~5 KB each:
`.../ftp/North_America_3_Factors_CSV.zip`,
`Europe_3_Factors_CSV.zip`, `Japan_3_Factors_CSV.zip`,
`Asia_Pacific_ex_Japan_3_Factors_CSV.zip`, `Emerging_5_Factors_CSV.zip`.

Correlating each region's `Mkt-RF` series against the others gives the
region correlation matrix — "is my geographic split actually
diversified, or one bet in five wrappers?"

## 3. Asset-class correlation — Damodaran, NYU Stern

`https://pages.stern.nyu.edu/~adamodar/pc/datasets/histretSP.xls`

Annual returns 1928→present for S&P 500, 3-month T-Bill, 10-year T-Bond,
Gold, Real Estate — the equities/bonds/cash/gold leg of the matrix.

**Known gap:** no crypto series exists in any of the above. The crypto
row in `data/correlations.md` is hand-entered and marked
`estimated: true` in its frontmatter rather than silently invented.

## FX rates — European Central Bank

`https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml`

Official daily EUR reference rates, no key required. `data/fx-rates.md`
is seeded from this feed (fetched 2026-08-03) and is editable directly
from **Data → FX rates** in the app — the file's `as_of` date is what
drives the staleness indicator shown next to every € total.

## Manual asset-class volatility refresh — Data → Correlations & volatility

Besides the batch `tools/build_reference_data.py` regeneration above, the
Correlations & volatility screen (`js/views/data/correlations.js`) accepts
a simple two-column CSV (`Asset Class,Volatility %`) and overwrites the
matching rows in `data/volatility.md`'s Asset Class Volatility table on
the spot — for a quick manual update from Damodaran's published annual
figures without re-running the full pipeline. It does not replicate
`tools/source_asset_class.py`'s historical-return-to-stdev statistics
client-side; that logic stays server-side only.

## Rejected: Stooq

Historically a good free OHLCV source; as of this build it serves a
JavaScript proof-of-work challenge page instead of raw CSV/data and is
not usable programmatically. Not used anywhere in this app.
